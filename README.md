# Lab Conexão Imobiliária — Portal Turma Beta

Portal exclusivo da Turma Beta do Lab Conexão Imobiliária, por Monica Helena Moreira Pires.

## Acesso

Senha de acesso: definida no `portal-app.jsx` (variável `SENHA`).

## Estrutura

- `index.html` — entrada do site
- `portal.css` — estilos do portal
- `portal-app.jsx` — aplicação React (Login → Fechadura → Portal)
- `data.js` — dados dos 14 encontros da turma
- `assets/` — imagens

## Deploy

Site estático puro — funciona em qualquer host (Vercel, Netlify, GitHub Pages).
